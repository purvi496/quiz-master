# Quiz Master

Quiz Master is a simple interactive quiz application built using HTML, CSS, JavaScript, and Bootstrap.

## Features

- Choose quiz difficulty
- Multiple-choice questions
- Timer for each question
- Score calculation
- Percentage calculation
- Grade calculation
- Speed bonus
- Answer review
- Quiz history
- Statistics
- Restart quiz option
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap 5

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select a difficulty level.
5. Click **Start Quiz**.
